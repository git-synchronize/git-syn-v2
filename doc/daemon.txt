This is new in v2.

The daemon monitors /srv/git or where ever the mirror has been setup on disk for any file changes with libuevent (dinosuar logo). So from my local repository, if I push to the local remote, then the daemon will see the changes written to the file system and trigger a synchronization job.

git-synd? git-synchronize-daemon?

Example directory structure:

```
.
├── git-syn-v2.git
└── git-syn.git

2 directories, 0 files
```

Event Loop: Git Push to Local -> Local File System Changed -> Execute Synchronization Job -> Report Status of Synchronization Job

The sync job will attempt to push all branches to all remotes listed in the config.

Failures? Error codes? Debug logging and log file locations.
